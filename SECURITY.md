# Security policy

This repository is the auto-grader for a Data Structures course. It is public so
that anyone can read exactly how submissions are scored. That also means a
weakness in it is visible to everyone, so please report one privately rather
than in a public issue.

## What to report

- **A way to score more than the work deserves** - for example a submission that
  can read or change the official tests, tamper with the grader, or make a test
  pass without the code doing what the test checks.
- **A way to see what should stay private** - other students' submissions or
  results, or the official tests and marking material, which are deliberately
  kept out of this repository.
- **A way for a submission to harm the machine that runs the grader** - the
  grader compiles and runs submitted Java code.
- **A secret committed by mistake** - a token, password or key anywhere in the
  repository or its history.

## How to report

Open the repository's **Security** tab, choose **Advisories**, then **Report a
vulnerability**. Only the maintainers can see the report. Please include what
you did, what happened, and the smallest example that shows it.

Please do not open a public issue or pull request for it, and do not share it
with classmates until it has been fixed.

Reporting a problem you found is welcome. Using one to raise your own or anyone
else's score is a different matter and is handled under the course's academic
integrity rules.

## Not a security issue

If you think your own submission was graded wrongly - a test you believe you
passed, a late penalty you think is incorrect - that is a grading question, not
a vulnerability. Raise it with your TA as usual.

## Supported versions

Only the current `main` branch is maintained and used for grading.
